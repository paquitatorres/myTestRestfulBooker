# MyTestRestfulBooker

## Descripción

Este proyecto forma parte del Challenge Final de XAcademy - Grupo 11.

El objetivo es automatizar pruebas sobre la pagina web utilizando Cypress junto con otras librerías, validando el cumplimiento de la funcionalidad como accesibilidad de la misma.

## Instalación
1. Clonar el repositorio 
```
git clone https://github.com/paquitatorres/myTestRestfulBooker.git
```
2. Ingresar al proyecto
```
cd myTestRestfulBooker
```
3. Instalar las dependencias
```
npm install
```
## Ejecutar las pruebas
Abrir Cypress
```
npx cypress open
```
Ejecutar todos los tests desde la terminal
```
npx cypress run
```
